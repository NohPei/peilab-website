# Project instructions

## Keep the visual maintenance guide current

Whenever making a substantial change to this website's organization or to how
people maintain and contribute to it, update
`_guides/show-me-website-map.html` as part of the same change.

- Use judgment about scope: changes to folder responsibilities, content types,
  metadata conventions, shared components, asset placement, or preview/check/
  publication workflows generally warrant a guide update.
- Explain the resulting structure and contribution steps using the guide's
  existing readable visual format. Keep its file paths and examples accurate.
- Document what a contributor needs to understand; do not enumerate every
  implementation detail or turn the guide into a change log.
- Routine bio edits, new entries of existing content types, image replacements,
  typo fixes and small styling tweaks do not require a guide update unless they
  change the maintenance workflow or make the guide inaccurate.
- Keep related instructions in README.md and CONTRIBUTING.md consistent when
  the affected workflow is also described there.
