# Saved project page template

Open [`templates/project-page.html`](../templates/project-page.html) in a browser.
This reusable HTML template preserves the approved ViLA layout with bracketed
placeholders for the title, authors, figure, result, approach and publication.
It includes optional demo and supplementary-material areas.

To try adjustments, duplicate the file inside `templates/`, then edit your copy.
Replace the figure placeholder with an image and alt text, and replace paper
links with real URLs. Keep draft assets beside the draft. Remove unused media
sections together with their navigation links when preparing a final design.
The contributor panel has a switch to preview the layout without those sections.

Both `templates/` and `_guides/` are excluded from the site build. Saving a draft
there does not add a project. The existing `templates/project.md` remains the
basic Markdown starter supported by the current shared project layout.

## Approved example

Open `_guides/show-me-project-vila.html` in a browser to review the proposed layout.
This is the original standalone visual reference, not an installed project layout.
ViLA's publication entry lives separately in `_publications/2025-vila.md` and
does not create a project page.

## Page order

1. Short project name, full title, authors, venue, award and paper link.
2. Main figure paired with the reported result and its comparison baseline.
3. Research question and a short explanation of the approach.
4. Optional demo video area.
5. Optional supplementary PDF, code and dataset resources.
6. Publication link.

The preview deliberately shows empty video/resource areas so their placement is
visible. Its contributor panel lets you hide them. A published page should omit
empty sections rather than show inactive links or imply materials are available.

## Example content and assets

- Copyable Markdown: `templates/examples/vila.md`.
- Original publication image: `_guides/assets/vila.jpg`.
- Intended content location: `_projects/vila.md`.
- Intended image location: `images/projects/vila/stadium.jpg`.
- Optional future video/PDF files: `files/projects/vila/`.

The Markdown example uses fields supported by the current project template and
starts with `published: false`. The styled HTML concept is not yet generated by
the shared layout. Adopting it would require updating `_layouts/project.html`,
adding reusable media/resource includes and project styles, and updating the
contribution instructions and visual maintenance guide together.

No demo, code repository, dataset, or supplement was supplied for this example.
When adding video support, local MP4 files can use an HTML video player; third-party
embeds require a compatible content-security policy. Normal external links can
be used without embedding a player.
